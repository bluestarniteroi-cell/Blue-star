# Blue Star — PWA Controle de Estoque

Este pacote transforma o controle de estoque em um aplicativo web instalável pelo Google Chrome no Android.

## Como publicar
1. Envie todos os arquivos desta pasta para uma hospedagem que ofereça HTTPS (por exemplo, GitHub Pages, Netlify ou outro servidor web).
2. Abra o endereço publicado no Chrome do Android.
3. Use **Instalar aplicativo** ou **Adicionar à tela inicial**.
4. Depois de instalado, o app abre em modo de aplicativo e mantém os dados no próprio aparelho.

## Logo
O arquivo `assets/logo.png` é um placeholder. Substitua-o pela logo oficial, mantendo exatamente o nome `logo.png`.

## Dados
Os produtos, movimentações e informações da empresa são salvos localmente no navegador (localStorage). Use **Exportar backup** para guardar uma cópia JSON.
